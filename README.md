# clau_release

클로(Clau)의 설치 파일을 배포하는 저장소입니다. 이 저장소에는 소스 코드가 없습니다.

- 받기: [릴리스](https://github.com/OCGK123/clau_release/releases/latest) 또는 [사이트](https://clau.ocgk123.uk)
- 문제 알리기: [Issues](https://github.com/OCGK123/clau_release/issues)

이 프로젝트는 비공개이며 클로즈드 라이선스입니다. 무료로 사용할 수 있지만 소스 코드는 공개하지 않으며, 무단 수정·개조, 원본과 수정본의 재배포, 상업적 재판매를 금지합니다. 공식 업데이트는 개발자만 제공합니다. 전체 약관은 [LICENSE](LICENSE)를 보세요.
